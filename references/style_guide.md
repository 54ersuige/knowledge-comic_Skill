# Style Guide · Knowledge Comic 知识漫画 · 文章内容评分维度

> 用户拍板（2026-09-20）：作者风格 = **三联生活周刊 × 远川研究所 × 半佛仙人** 三合一。
>
> 本文档是**单一事实来源** —— Skill 内的 `planner` 生成 / `review.py` 评审 / `canon.py` 一致性检查**全部按本文档打分**。
>
> 修改本文档时同步更新：`canon.md`（术语 / 数字统一表）

## 1. 作者风格定义 · 三合一公式

### 1.1 三联生活周刊 × 人物 · 开头

| 维度 | 规则 |
|---|---|
| **叙事口吻** | 庄重、克制、不煽情 |
| **事实优先级** | 数字 + 时间 + 地点，每个论点必配历史背景 |
| **段落长度** | 开篇导语单段；正文一句一段，**无首行缩进**（v0.3.8 定版） |
| **拒绝** | 表情包、口语、网络流行语、"震惊体"、"不得不看" |

**样板**：
> 1347 年，一艘载有货物和乘客的船只抵达西西里岛的墨西拿港。船员中许多人已经生病或死亡，但港口官员并未意识到这次靠岸将带来怎样的灾难。

### 1.2 远川研究所 · 正文

| 维度 | 规则 |
|---|---|
| **数据驱动** | 每个论点配 1 个具体数字（年份 / 比例 / 数量） |
| **商业 / 当代映射** | 每章末尾有"这意味着..."的延伸（连接历史 → 当代） |
| **视角** | 大事件看小细节（如瘟疫看工人议价、宗教怀疑看艺术转变） |
| **拒绝** | 鸡汤、空泛口号、"我们应当反思" |

**样板**：
> 死亡率高达三分之一。劳动力价值上升，农民和工人获得更多谈判权，封建制度开始松动 —— 这一结构性变化，比瘟疫本身更具历史穿透力。

### 1.3 半佛仙人 × 混子曰 · 结尾

| 维度 | 规则 |
|---|---|
| **金句收束** | 结尾一段是 ≤ 30 字的精炼观点，能独立传播 |
| **反直觉** | 至少 1 句带"反转"或"反常识"角度 |
| **避免说教** | 不直接讲道理，让事实 / 数字本身说话 |
| **拒绝** | "总而言之"、"综上所述"、"我们应该..." |

**样板**：
> 黑死病不仅是一场灾难，更是中世纪向近代转型的催化剂。

### 1.4 三合一公式（硬约束）

| 段落位置 | 必须满足 |
|---|---|
| **开头卷首** | 三联式（深度 + 历史背景 + 数字） |
| **每章正文** | 远川式（数据 + 商业 / 当代映射） |
| **结尾金句** | 半佛式（≤ 30 字 + 反直觉 + 不说教） |

## 2. 表达深度指标 · 评分维度 1（30 分）

### 2.1 每章必备元素（缺一项扣 5 分，最高扣 15 分）

| 元素 | 示例 |
|---|---|
| **数字** | "1347 年"、"60% 死亡率"、"三分之一" |
| **画面** | "船只靠岸"、"鸟嘴医生"、"集体墓穴" |
| **原因 / 机制** | "鼠疫通过跳蚤叮咬传播"、"商业路线成传播高速公路" |
| **highlight（章节大字）** | "1347"、"跳蚤"、"1/3"（4-8 字，跨章唯一） |

### 2.2 金句密度（每章必须）

- **金句定义**：≤ 30 字、能脱离上下文独立传播、表达一个清晰观点
- **密度**：每章 ≥ 1 句金句（数据卡里的话是引文，不算）
- **反直觉**：至少 1 句带"反转"或"反常识"角度

### 2.3 章节结构（每章必须，按顺序）

1. 章节大字（highlight，4-8 字，朱砂红 80px）
2. 中文数字章节号（壹贰叁...）
3. 章节题（caption，10-20 字，h2）
4. 图（章节插图）+ 图下文言蒙版（`dialogue`，逐字出原著）
5. body 正文（**100-150 字**，三拍结构，**一句一段、无首行缩进**）
6. 定格瞬间（`punchline`，白话金句 10-22 字）

> ⚠️ v0.3.8 变更：正文不再是"长段落 + 段首缩进 + line-height 2.0"。
> 现在一句一段、去缩进，段边界由段间距标明。详见 `templates.md`。

## 2.5 正文文风铁律（v0.3.18 定版 · 硬约束）

> 这两条是「读者看不懂」和「读者没耐心」的直接解药，
> 已写进 `planner.py` 的 `PLANNER_SYSTEM_PROMPT` §3.1（三拍）/ §3.2（术语翻译）。
>
> ⚠️ v0.3.24：prompt 章节已重编号（原「铁律 4.1 / 4.2」→ 现 §3.2 / §3.1，
> 术语翻译在前、三拍在后）。按旧编号去 prompt 里找会找不到。

### 2.5.1 术语翻译铁律（prompt §3.2）

**问题**：读者看不懂，90% 是因为**文言术语裸奔** —— 一个抽象词直接砸出来，
没有一句人话解释，读者读完只知道"作者在用我不懂的词"。

| 规则 | 说明 |
|---|---|
| **任何术语首次出现必须解释** | 格式 `术语（大白话解释）` 或 `术语，意思就是……`，同一句或紧接下一句 |
| **一页最多 1 个术语** | 术语密度上限 = 1。超过必然超字数，结果每个都没解释清楚 |
| **解释用生活类比** | 不是同义替换（❌"伐谋即谋略" → ✅"对手还没动手，你先看穿他心里想要什么"） |
| **专有名词免解释** | 人名 / 地名 / 朝代 / 事件名 / 官职（烛之武、新郑、春秋、长平之战、平原君） |

**禁用裸术语清单**（不解释直接出现 = 违规）：
上兵 / 伐谋 / 伐交 / 庙算 / 奇正 / 势 / 全胜 / 釜底抽薪 / 合纵连横 /
欲擒故纵 / 以全争于天下 / 兵家极意 / 存乎一心 …

**改写对照**（照这个标准写）：

| ❌ 裸术语 | ✅ 术语+人话 |
|---|---|
| 孙子将博弈分为三层：上策是伐谋，中策是伐交，下策是攻城 | 孙子把赢对手分成三档。第一档最省力：对手还没动手，你先看穿他心里想要什么，把这念头掐灭。第二档费点劲：对手有盟友，你去挑拨，让盟友先跑。第三档最费力：硬攻城池，拿人命去填 |
| 最高境界是"以全争于天下"，这才是兵家极意 | 孙子觉得最高明的赢法，是自己一个人都不折损，就把对方压到服软 |
| 战例二·鲁仲连解围：战国邯郸之围，不着一兵不发一矢 | 鲁仲连解邯郸之围：公元前二五七年，秦军围住赵国都城，他没动一兵一卒，就让秦军自己撤了 |

### 2.5.2 正文三拍结构（prompt §3.1）

body 固定三拍，合计 100-150 字：

| 拍 | 字数 | 职责 |
|---|---|---|
| **第 1 拍 · 讲事** | 40-50 字 | 讲清楚这一页发生了什么（时间 / 地点 / 人物 / 动作） |
| **第 2 拍 · 说破** | 40-60 字 | 把这一步的"**为什么**"用人话说出来 —— **最容易丢、也最关键的一拍** |
| **第 3 拍 · 落点** | 20-30 字 | 一句判断 / 感受，**不重复画面** |

三拍之间不要每句都换行，读起来要有节奏。

### 2.5.3 白话 vs 文言的分层（v0.3.10 / v0.3.11）

历史 / 经典故事类有三个字字段，**各司其职、不可混用**：

| 字段 | 语体 | 位置 | 约束 |
|---|---|---|---|
| `body` | **现代白话（信达雅）** | 图下正文 | 读者未必读得懂文言，正文必须用日常能懂的话把故事讲清楚 |
| `dialogue` | **文言原文** | 叠在图片下缘蒙版 | **逐字出自原著**，不得杜撰 / 润色；每页必填，留空比写错更糟但仍好过编造 |
| `punchline` | **白话金句** | 「定格瞬间」卡 | 10-22 字，点题 + 记忆点，**不写文言** |

**用户原话（v0.3.11）**：
> 「我的读者是不一定能读懂这些文言文，需要翻译成信达雅的现代语言，
> 这些文言文文字内容我希望可以放在图片中，显得更加专业」
> 「文言文要集成在图片中在图片的下方，用类似蒙版的效果集成在图片上」

### 2.5.4 分寸与禁写

| 禁写 | 原因 | 拦截 |
|---|---|---|
| 「（或…）」「（实际为…）」「（一说…）」 | LLM 不确定时的自我暴露 | preflight **阻塞** `HEDGING` |
| 「极限测试」「活体武器」「情绪价值」「内卷」「破防」「降维打击」 | 现代口水词，史传要有史传的分寸 | preflight **warn** `MODERN_TONE` |
| 复述画面里已经看得到的东西 | 图为主、文字为脚注，重复即冗余 | planner prompt 铁律 4 |
| 元叙事（"远川研究所式的视角告诉我们"） | 跳出文本点名引用源 | planner prompt 事实核查第 4 条 |
| "总而言之 / 综上所述 / 我们应该…" | 说教 | style_guide §1.3 |

## 3. 一致性指标 · 评分维度 2（30 分）

### 3.1 术语统一（缺一项扣 3 分，最高扣 9 分）

| 类别 | 规则 |
|---|---|
| **同一概念** | 全文用同一词（如"鼠疫"vs"黑死病"——选定一个，全文统一） |
| **时间表达** | "X 年"vs"X 世纪"——交替使用但每个章节只用一种 |
| **人名 / 地名** | 同一人物用同一译名（如"墨西拿"vs"梅辛那"——统一） |

### 3.2 数字一致（缺一项扣 3 分，最高扣 9 分）

| 类别 | 规则 |
|---|---|
| **同一数字** | 跨章一致（如"死亡率三分之一"和"33%"必须用一种） |
| **时间链** | 时间顺序不矛盾（1347 → 1348 → 1349 不能错乱） |
| **人物 / 地点** | 跨章身份一致 |

### 3.3 视觉锚点统一（缺一项扣 4 分，最高扣 12 分）

| 类别 | 规则 |
|---|---|
| **同系列手绘风格** | 所有图用同一 handraw-style 编号 |
| **关键视觉锚点** | key_visual 跨章保持（如"卡通狐狸"作为旁白者） |
| **highlight 跨章唯一** | 每个章节大字（4-8 字）跨章唯一，不重复 |
| **风格一致** | chinese_lianhuanhua_classic 5 张必须都戴敦邦派笔法（不可出现 1 张跑偏到现代写实） |

## 4. 作者风格匹配度 · 评分维度 3（40 分）

### 4.1 开头（三联式 · 15 分）

| 评分项 | 满分 | 评分标准 |
|---|---|---|
| 卷首题词（preface）合理 | 3 | ≤ 12 字、有诗意、不空泛 |
| 副标题（subtitle）真实 | 3 | 有出处 / 学术来源（如"基于历史档案..."） |
| 题记（epigraph）符合 | 3 | 1 句话能定调、有诗意 |
| 导语（summary）有钩子 | 3 | 第一句能吸引读完整篇 |
| 卷首题词颜色为朱砂红（c 模板）| 3 | 视觉一致性 |

### 4.2 正文（远川式 · 15 分）

| 评分项 | 满分 | 评分标准 |
|---|---|---|
| 每章有具体数字 | 5 | ≥ 3 章含数字 |
| 有商业 / 当代映射 | 5 | ≥ 1 章有"这意味着..."句式 |
| 视角立体 | 5 | 不只是"是什么"——含"为什么 / 如何" |

### 4.3 结尾（半佛式 · 10 分）

| 评分项 | 满分 | 评分标准 |
|---|---|---|
| 收束 ≤ 30 字 | 4 | 简短精炼 |
| 反直觉 / 反常识 | 3 | 至少 1 句 |
| 不说教 | 3 | 没有"我们应当 / 总之" |

## 5. 总分公式 & 通过阈值

```
总分 = 维度1（深度 / 30）+ 维度2（一致性 / 30）+ 维度3（作者风格 / 40）

通过阈值：≥ 90 分（v2 - 严化）
自动重试：< 90 分 → planner 重跑（最多 2 次）
硬性失败：任一维度 < 70% 满分 → 标红 + 用户拍板是否接受
事实错误：发现硬性事实错误 → 直接 FAIL（不允许发布）
```

| 维度 | 满分 | 失败阈值 |
|---|---|---|
| 深度 | 30 | < 21 |
| 一致性 | 30 | < 21 |
| 作者风格 | 40 | < 28 |

## 6. ⚠️ 硬性事实核查（planner 必须遵守）

**任何历史 / 学术事实错误都会导致直接 FAIL。**

| 规则 | 例子 |
|---|---|
| **时间人物因果** | 但丁 1321 年去世，不能讨论 1347 年事件时说他"家族因黑死病灭绝" |
| **不要凭空编造** | "X 家族 Y 后裔几乎死绝" 必须是公开可查的事实，不是 LLM 编造 |
| **引用具体数字** | "X%" 必须有明确出处或公认估算，不能拍脑袋 |
| **避免元叙事** | 不写"远川研究所式的视角告诉我们"——直接写远川式内容，不点名引用源 |
| **不要堆砌人物** | 不为了显得有文化就堆一堆名人名字 |
| **史实不避讳（v0.2.4 典故案例）** | 用户明确要求"食人"等争议段必须保留，不能跳过。张巡杀爱妾、许远杀奴以食军要直写。 |
